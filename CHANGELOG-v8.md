# Marketplace v8 — магазин, отзывы, Telegram-бот

## Интерфейс
- В личном кабинете магазина добавлены 3 темы оформления, выбор белого/чёрного цвета текста в верхней панели и отдельный URL-фон нижней части витрины.
- Логотип сохраняется в верхней панели магазина; карточки магазина показывают его как логотип, а не как фон всей карточки.
- Добавлено редактирование описания личного профиля.
- В меню добавлен переключатель светлой/тёмной темы; боковое меню выезжает слева, открывается по логотипу и закрывается свайпом/кнопкой.
- На мобильном viewport запрещён масштаб страницы; верхняя панель сдвинута вниз, чтобы не пересекаться с интерфейсом Telegram.
- Магазинные карточки, профиль и раздел отзывов используют данные из серверных API вместо восстановления старых демо-объявлений/отзывов из localStorage.

## Сервер/API
- Магазинные тема, цвет текста и фон сохраняются только для владельца магазина.
- Смена названия, описания, логотипа и владельца доступна из админ-панели и проверяется на сервере; одному Telegram ID разрешён только один магазин.
- Публикации хранятся в `marketplace_listings`; подписчики профилей/магазинов получают внутреннее уведомление и сообщение бота (последнее — если они уже нажали Start).
- Отзывы сохраняются в `marketplace_reviews`, проходят модерацию, отображают оценки 1–5 звёзд; получатель может оспорить опубликованный отзыв. Получателю отправляется уведомление с deep link.
- Статус жалобы отображается как «Взята в работу», «Проверена модерацией» или «Завершена». Финальное решение владельца/заместителя отправляет уведомление заявителю; при наказании текст благодарит за содействие и сообщает о мере.
- В статистике платформы учитываются Telegram-пользователи, хотя бы раз открывшие Mini App. Рефералы считаются только при первом `/start` бота с корректным `?start=<telegram_id>`.
- Массовые уведомления владельца сохраняются во внутренние уведомления и отправляются пользователям, ранее запустившим бота.
- Добавлен сценарий `/complaint` для жалобы на модерацию; текст передаётся владельцу `@nukm0`.

## Перед развёртыванием
1. Выполнить целиком `supabase/schema.sql` в Supabase SQL Editor.
2. В Vercel задать `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET`, `NEXT_PUBLIC_APP_URL`, `APP_URL`, `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`.
3. Установить Telegram webhook на `https://ВАШ-ДОМЕН/api/telegram/bot` и передать секретный заголовок Telegram через `secret_token`.
4. Redeploy Vercel и проверить `npm run build`.

В этом подготовительном окружении полная сборка не подтверждена: зависимости Next.js/React не были установлены. Данный changelog не означает, что интеграции уже проверены против реального Telegram-бота/Supabase в продакшене.
