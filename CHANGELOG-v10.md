# Marketplace v10 — профиль, кабинет магазина, подписки

## Интерфейс
- Возвращён раздел «Мои подписки» в основную боковую и нижнюю навигацию.
- В личном кабинете: карточка реферальной ссылки, кнопка настроек у аватара, отдельная статистика профиля, блок отзывов и только частные объявления.
- Настройки личного кабинета: описание, публичная обложка, публичный фон и цвет текста; личный фон платформы сохраняется только в локальном браузере.
- Кабинет магазина: обложка, логотип, владелец, описание, статистика публикаций/подписчиков/просмотров, отзывы и закреплённая кнопка создания объявлений.
- Форма настройки магазина открывается поверх текущей страницы, загруженные параметры сохраняются в Supabase.
- Владелец платформы может менять имя, логотип и владельца магазина в административной панели. При передаче магазина ID продавца и username обновляются у связанных объявлений.
- Для владельцев магазина добавлена инструкция «Как пользоваться магазином» в FAQ.
- Добавлена жалоба на объявление с категориями причин, описанием и приложением до трёх изображений.
- Улучшен контраст светлой темы: тёмные заголовки, читаемые метки, подсвеченные карточки и градиентные тени. Цветовые темы профиля и магазина теперь визуально выделяют карточки объявлений.

## Данные и сервер
- При удалении магазина архивируются его подписчики, затем удаляются магазинные объявления, отзывы, просмотры, подписки, связанные жалобы и данные модерации. Архив подписки показывает текст о том, что магазин был удалён.
- Добавлен уникальный индекс `(listing_id, viewer_telegram_id)` для уникального учёта просмотров; перед созданием индекса старые дубликаты удаляются.
- Добавлены агрегированные views для счётчиков просмотров объявлений, профилей и магазинов.
- Счётчики подписчиков и просмотров читаются из агрегированных views с fallback на таблицы, если view недоступен.
- Независимые запросы в серверной сессии выполняются параллельно, чтобы сократить задержку.
- Исправлены разрешения загрузки изображений профиля для обычных авторизованных пользователей; настройки магазина доступны только подтверждённому владельцу магазина.
- Изменение названия/логотипа/владельца магазина на сервере разрешено только владельцу платформы.

## Перед деплоем
1. Сделайте резервную копию Supabase.
2. Выполните полный `supabase/schema.sql` в Supabase → SQL Editor. Скрипт включает дедупликацию просмотров и индексы/представления v10.
3. Убедитесь, что в Vercel настроены только серверные секреты в Environment Variables, и выполните Redeploy.
4. После публикации проверьте: сохранение настроек личного профиля и магазина, создание/удаление объявлений, счётчики просмотров, жалобу на объявление и удаление тестового магазина с подписчиком.
